## 4.2 命令执行安全边界与危险命令拦截（P0-6，落实 P-2）

### 现状
四个「命令落地 PTY」入口**全部无确认**：
- 手输回车（xterm onData → [ssh_pty_write](../../src/components/TerminalView.tsx#L262-L264)）
- Snippet（[executeSnippet](../../src/stores/serverStore.ts#L646-L656)）
- 批量执行（[BatchExecModal handleExecute](../../src/components/BatchExecModal.tsx#L118-L170)）
- AI 生成命令（当前 no-op，接通后须管控，[01 B-4](./01_现状审计与问题清单.md#b-4--ai-生成命令发送到终端违背-p-1-的设计隐患)）

### 推荐：统一「危险命令网关」
所有入口在写入 PTY 前经过同一网关（前端为主，后端二次校验）：

1. **规则库（正则，规划新增，可配置）**，至少覆盖：
   - 文件系统破坏：`rm -rf /`、`rm -rf ~`、`rm -rf /*`、`find ... -delete`、`shred`、`mkfs`、`dd of=/dev/*`
   - 系统控制：`shutdown`、`reboot`、`halt`、`poweroff`、`init 0/6`、`systemctl stop/disable`（关键服务）
   - 权限/账户：`chmod -R 777 /`、`chown -R`、`passwd`、`userdel`、`visudo`
   - 数据库：`DROP DATABASE`、`DROP TABLE`、`TRUNCATE`、`DELETE` 无 `WHERE`
   - 进程：`kill -9 1`、`pkill`、`killall`
   - 磁盘/分区：`fdisk`、`parted`、`> /dev/sda`
2. **分级**：
   - `block`（永不允许自动执行，须显式输入确认文本）
   - `confirm`（弹确认框，展示命令 + 目标主机清单）
   - `warn`（提示但可继续）
3. **确认 UI 必含**：完整命令、将影响的主机/会话列表（批量场景逐台列出）、不可逆提示；批量执行须展示「N 台主机」并二次确认。
4. **AI 来源命令**：默认 `confirm` 起步，破坏性命令即使 AI 生成也**永不自动执行**（P-1），必须用户点击「确认执行」。

### 契约建议
- 前端 `commandGuard(command): {level, matched}` 工具，Snippet/批量/AI/手输共用。
- 后端 `ssh_pty_write`/`ssh_execute` 增加**可选**的 `confirmed: bool` 标记用于审计（非主要防线，前端为主，避免绕过 UI 的调用）。

## 4.3 AI 不自动执行破坏性命令（P0，落实 P-1）

### 现状定性
- 「发送到终端」当前是 no-op（[onCommandGenerated={() => {}}](../../src/App.tsx#L963)），歪打正着形成安全缓冲。
- 风险在于**修复接通时**若直接写 PTY，会把 AI 幻觉命令直接执行。

### 推荐（接通即受约束）
1. AI 生成命令**只填充输入框/建议区**，不直接写 PTY。
2. 用户主动「执行」时，仍过 4.2 危险命令网关。
3. 破坏性命令：AI 生成 → 标红 → 用户输入确认文本（如 `DELETE`）才执行。
4. 多智能体（若补齐）产出的任何命令同样受此约束，**禁止 agent 自动落地 PTY**。
5. AI 请求上下文**不得包含**密码/私钥/Key（见 4.5，P-4）。

## 4.4 主机公钥校验与 known_hosts（P0-1）

### 现状
[check_server_key 恒返回 Ok(true)](../../src-tauri/src/ssh.rs#L68-L74)，注释自认应验证 known_hosts。MITM 可劫持会话、窃取认证。

### 推荐
1. 首次连接：计算并展示主机指纹（ED25519/RSA），弹「信任此主机？」对话框，用户确认后写入 `~/.z-terminal/known_hosts`。
2. 后续连接：校验 known_hosts；**指纹变更时强警告**（可能是 MITM 或主机重装），默认拒绝，需用户显式覆盖。
3. 提供 known_hosts 管理 UI（查看/删除条目）。
4. 契约：`check_server_key` 改为返回 `Unknown`/`Match`/`Mismatch` 三态，前端据此交互；不再无条件 `Ok(true)`。

## 4.5 密钥 / 环境不泄漏到日志（P0，落实 P-4）

### 现状
| 泄漏面 | 证据 |
|--------|------|
| 会话日志全量明文落盘，无脱敏/开关/加密 | [write_log](../../src-tauri/src/ssh.rs#L614-L625)、[01 D-2](./01_现状审计与问题清单.md#d-2--会话日志全量明文落盘无脱敏无开关无加密) |
| SSH 密码/私钥明文持久化 + 10 份明文备份 | [config.rs](../../src-tauri/src/config.rs#L5-L30)、[01 D-1](./01_现状审计与问题清单.md#d-1--ssh-密码私钥明文持久化--明文备份) |
| AI Key 明文 localStorage；Gemini Key 进 URL | [aiStore](../../src/stores/aiStore.ts#L51-L59)、[aiClient](../../src/services/aiClient.ts#L31-L32) |
| export_config 明文导出凭证到任意路径 | [config.rs](../../src-tauri/src/config.rs#L342-L349) |

### 推荐
1. **日志治理**：
   - 默认可关闭；提供脱敏规则（正则遮蔽 `password=`、`-p<...>`、`BEGIN ... PRIVATE KEY`、`token=`、`Authorization:` 等）。
   - 可选加密落盘；日志文件权限 0600（POSIX 平台）。
   - 明确保留期与自动清理。
2. **凭证存储**：
   - 迁移到系统钥匙串（macOS Keychain / Windows Credential Manager / libsecret），或至少用主密钥加密后落盘。
   - 配置文件权限 0600；备份同样加密。
   - 连接时密码/私钥经 IPC 传输后**不在前端 state 长期驻留**（当前 [明文传入](../../src/stores/serverStore.ts#L194-L207)）。
3. **AI Key**：走加密存储；Gemini Key 改 header（不进 URL，[当前 query](../../src/services/aiClient.ts#L31-L32)）。
4. **导出**：export_config 默认**不含**密码/私钥（脱敏导出），如需含凭证须显式勾选 + 强警告 + 加密。
5. **AI 上下文脱敏**：发送给 AI 的终端内容/命令须过滤凭证（与 4.3 协同）。

## 4.6 远程命令注入防护（P0-2）

### 现状
诊断命令 host 直接 `format!` 进 shell：[ping](../../src-tauri/src/commands.rs#L735-L760)、[port](../../src-tauri/src/commands.rs#L763-L791)、[traceroute](../../src-tauri/src/commands.rs#L794-L818)。`1.1.1.1; rm -rf ~` 会被执行。

### 推荐
1. 复用已有 [shell_escape](../../src-tauri/src/ssh.rs#L920-L923)（SFTP 回退路径已用）转义所有外部输入。
2. 诊断命令改为**参数化/白名单**：host 校验为合法 IP/域名（正则），port 校验为 1-65535 整数，count 限定范围。
3. 禁止把用户输入直接拼进 shell 字符串；优先用 `exec` 传参而非 shell 解析。

## 4.8 Tauri 与 shell 权限收敛（P1）

### 现状
- CSP 关闭：[tauri.conf security.csp=null](../../src-tauri/tauri.conf.json#L22-L24)。
- 宽 capabilities：[fs:default + shell:default](../../src-tauri/capabilities/default.json#L6-L12)。
- custom_css 任意注入 + 背景图 `file://` 拼接（[TerminalView](../../src/components/TerminalView.tsx#L336-L368)）。
- `shell:default` 允许 `plugin:shell|open` 打开任意 URL/路径（[链接点击](../../src/components/TerminalView.tsx#L437-L441)）。

### 推荐
1. **启用 CSP**：限定 `connect-src`（AI baseUrl 白名单）、`img-src`、`style-src`；禁止内联任意脚本。
2. **收敛 capabilities**：移除 `shell:default` 的通配，仅允许受控的 opener；`fs` 限定到应用数据目录。
3. **文件命令路径白名单**：[read_file_content](../../src-tauri/src/commands.rs#L721-L725)、[read_file_as_base64](../../src-tauri/src/commands.rs#L727-L732)、[open_file_with_default_app](../../src-tauri/src/commands.rs#L691-L709) 复用 [read_session_log 的 canonicalize+starts_with 范式 🟢](../../src-tauri/src/config.rs#L447-L458)。
4. **custom_css/背景图**：限制来源（仅本地受控目录），或经 sanitize；背景图路径校验。

## 4.9 审计（Audit）

### 现状
无操作审计日志（谁、何时、对哪台主机、执行了什么命令）。

### 推荐（规划新增）
1. 记录关键操作：连接/断开、命令执行（尤其危险命令确认/拒绝）、批量下发、配置导出、AI 命令生成与执行。
2. 审计日志**脱敏**（不含密码/私钥/Key，遵守 P-4），独立于会话日志，只追加、防篡改（哈希链可选）。
3. 提供审计导出（CSV/JSON），供合规回溯。

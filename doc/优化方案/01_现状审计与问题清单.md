## B. 安全边界（P0 集中区）

### B-1 🔴 SSH 主机公钥恒自动接受，无 known_hosts 校验（MITM）
- 证据：[check_server_key 直接返回 Ok(true)](../../src-tauri/src/ssh.rs#L68-L74)，注释自认「生产环境应验证 known_hosts」。
- 影响：任何中间人都能被无条件信任，会话可被劫持，密码/私钥认证过程可被窃取。违反 P-3 的隔离前提（连接本身不可信）。
- 优先级：P0-1。

### B-2 🔴 诊断命令字符串拼接未转义 → 远程命令注入
- 证据：
  - [ssh_diagnose_ping: `format!("ping -c {} {} 2>&1", c, host)`](../../src-tauri/src/commands.rs#L735-L760)
  - [ssh_diagnose_port: host/port 直接拼进 `nc`/`/dev/tcp` 命令](../../src-tauri/src/commands.rs#L763-L791)
  - [ssh_diagnose_traceroute: `format!("traceroute {} ...", host)`](../../src-tauri/src/commands.rs#L794-L818)
- 对比：SFTP 回退路径**有**转义 [shell_escape](../../src-tauri/src/ssh.rs#L920-L923)，但诊断命令未复用。
- 影响：`host` 来自前端用户输入（DiagnosticModal），形如 `1.1.1.1; rm -rf ~` 会被远端 shell 执行。
- 优先级：P0-2。

### B-3 🔴 危险命令零拦截（手输/Snippet/批量/AI 四入口）
- 证据：
  - Snippet 直接写 PTY：[executeSnippet `ssh_pty_write` command+"\n"](../../src/stores/serverStore.ts#L646-L656)
  - 批量执行直接写 PTY：[BatchExecModal handleExecute](../../src/components/BatchExecModal.tsx#L118-L170)
  - 全仓 `Modal.confirm`/`Popconfirm` 仅用于删除类操作（ServerList/SftpPanel/SnippetsPanel/SettingsModal），**无任何命令风险筛查**。
- 影响：违反 P-2。`rm -rf /`、`mkfs`、`shutdown`、`dd of=/dev/sda` 等可无确认下发到一台或多台服务器。
- 优先级：P0-6。

### B-4 🔴 AI 生成命令「发送到终端」违背 P-1 的设计隐患
- 证据：[AINaturalLanguageCommand 生成命令](../../src/components/AINaturalLanguageCommand.tsx#L28-L61)；App 传入的回调是 no-op [onCommandGenerated={() => {}}](../../src/App.tsx#L963)，组件内「发送到终端」按钮仅 [复制剪贴板 + 调用空回调](../../src/components/AINaturalLanguageCommand.tsx#L114-L120)。
- 现状定性：功能**未接通**（既是缺陷也是「歪打正着」的安全缓冲）。修复接通时**必须**内置危险命令确认（P-1/P-2），否则会把 AI 幻觉命令直接执行。
- 优先级：P0（修复方式受 P-1 约束）。

### B-5 🔴 CSP 关闭 + 宽泛 capabilities + 自定义 CSS 注入
- 证据：[tauri.conf security.csp = null](../../src-tauri/tauri.conf.json#L22-L24)；[capabilities 授予 fs:default + shell:default](../../src-tauri/capabilities/default.json#L6-L12)；[TerminalView 将 settings.custom_css 注入 <style>](../../src/components/TerminalView.tsx#L352-L368)；[背景图 `file://` 拼接](../../src/components/TerminalView.tsx#L336-L349)。
- 影响：无 CSP 下，前端 fetch 任意 baseUrl（AI）、注入任意 CSS、`file://` 加载本地资源均不受限；`shell:default` 允许 `plugin:shell|open` 打开任意 URL/路径（[链接点击](../../src/components/TerminalView.tsx#L437-L441)）。攻击面偏大。
- 优先级：P1（需与 AI fetch 白名单一起收敛）。

### B-6 🔴 任意本地文件读取/打开命令无路径校验
- 证据：[read_file_content](../../src-tauri/src/commands.rs#L721-L725)、[read_file_as_base64](../../src-tauri/src/commands.rs#L727-L732)、[open_file_with_default_app](../../src-tauri/src/commands.rs#L691-L709) 均直接吃前端传入 path，无 A-4 那样的目录白名单校验。
- 影响：若前端被诱导（XSS/恶意链接），可读取任意本地文件或以默认程序打开任意路径。与 A-4 的正确范式不一致。
- 优先级：P1。

## C. 并发、性能与 PTY 数据面

### C-1 🔴 全局 SESSIONS 单 Mutex 跨 await 持锁（队头阻塞）
- 证据：[static SESSIONS: OnceCell<Arc<Mutex<HashMap>>>](../../src-tauri/src/commands.rs#L8-L16)；
  - [ssh_execute 先 `sessions().lock()` 再在锁内 `sess.execute().await`](../../src-tauri/src/commands.rs#L171-L194)——整个远程命令执行期间持有全局锁；
  - [ssh_pty_write 同样锁内 `pty_write().await`](../../src-tauri/src/commands.rs#L621-L645)；[ssh_get_server_info 锁内执行组合脚本](../../src-tauri/src/commands.rs#L852-L866)。
- 影响：任一标签跑长命令（或 `ssh_get_server_info` 的 `top -bn2 -d1` 采样约 1s+），**所有其它标签的键入/SFTP/诊断全部阻塞**。直接违反 P-3。
- 优先级：P0-3。

### C-2 🔴 PTY 输出无批处理/无背压，逐块 emit + 同步写日志在热路径
- 证据：[PTY 事件循环每个 ChannelMsg::Data 都 `app.emit("pty-output")` 且调用 `write_log`](../../src-tauri/src/ssh.rs#L537-L609)；[write_log 每次 lock + 格式化时间戳 + write_all](../../src-tauri/src/ssh.rs#L614-L625)；前端 [ptyOutputHandler 每事件 `term.write(data)`](../../src/components/TerminalView.tsx#L210-L255)。
- 影响：`cat bigfile`/`yes`/`tail -f` 高频输出时，每块一次 IPC + 一次磁盘锁写，IPC 洪泛、渲染抖动、日志锁竞争拖慢读循环。无 xterm 写回调背压。
- 优先级：P1（性能红线，量化目标见 06）。

### C-3 🟡 渲染仅用默认 DOM renderer，无 WebGL/Canvas addon
- 证据：[package.json 仅 @xterm/xterm + @xterm/addon-fit](../../package.json#L20-L21)，无 `@xterm/addon-webgl`/`addon-canvas`；[Terminal 初始化](../../src/components/TerminalView.tsx#L180-L196)。
- 影响：大滚动回看 + 高频输出下 CPU 占用偏高。属待实测确认的优化点（🟡）。
- 优先级：P2。

### C-4 🔴 每个 pane 各注册一个全局 `pty-output` 监听，O(N) 扇出
- 证据：[TerminalView listen("pty-output") 按 session_id 过滤](../../src/components/TerminalView.tsx#L257-L259)；[BatchExecModal 另注册一个且依赖 tabs 反复重订阅](../../src/components/BatchExecModal.tsx#L56-L85)。
- 影响：N 个 pane 时每条输出被 N 个监听器接收再各自过滤；BatchExec 打开时每次 tabs 变化都重订阅。CPU 浪费、潜在重复处理。
- 优先级：P2。

### C-5 🔴 `execute()` 输出无上限累积在内存
- 证据：[execute 把所有 Data/ExtendedData push 进一个 String](../../src-tauri/src/ssh.rs#L283-L310)，无大小上限、无超时。
- 影响：远端命令产出海量输出（如 `cat /dev/urandom`）会 OOM 或长时间挂起（且叠加 C-1 全局锁 → 冻结全应用）。
- 优先级：P1。

### C-6 🔴 convertEol 与 PTY 输出可能重复处理换行
- 证据：[Terminal 配置 convertEol: true](../../src/components/TerminalView.tsx#L189)。远程 PTY 通常已输出 `\r\n`，convertEol 再把 `\n`→`\r\n`。
- 影响：🟡 待验证——特定程序输出可能出现多余回车/错位。列为待实测。
- 优先级：P2。

### C-7 🔴 端口转发任务在 disconnect 时未显式 abort
- 证据：[disconnect 仅 take pty_writer/resize/log/sftp/handle](../../src-tauri/src/ssh.rs#L889-L917)，未遍历 `forwards` map 调 abort（仅 [stop_forward 单个 abort](../../src-tauri/src/ssh.rs#L875-L887)）。
- 影响：断开后转发任务的 JoinHandle 仍存活，直到底层 accept/copy 出错才退出，资源回收不及时。
- 优先级：P2。

## F. 会话生命周期与可靠性

### F-1 🔴 分屏多 pane 断线重连只恢复 pane[0]
- 证据：[reconnectTab 成功后仅 `i === 0` 的 pane 赋新 sessionId](../../src/stores/serverStore.ts#L830-L849)，其余 pane 停留在 [重连前被设的 connecting 且 sessionId=undefined](../../src/stores/serverStore.ts#L805-L821)。
- 影响：违反 P-3。分屏用户断网恢复后，非主 pane 永久「连接中」假死。
- 优先级：P1。

### F-2 🔴 自动重连固定 3s、无退避、无上限
- 证据：[reconnectTab `await setTimeout 3000` 后单次重连](../../src/stores/serverStore.ts#L823-L828)；[pty-closed 触发 auto_reconnect](../../src/stores/serverStore.ts#L892-L928)。失败后置 error，但下一次 pty-closed 或手动又会触发，无指数退避、无最大次数、无抖动。
- 影响：服务器长时间不可达时反复每 3s 冲击，且无「已放弃」终态提示。
- 优先级：P1。

### F-3 🔴 连接超时用 Promise.race，未取消底层 Rust 连接
- 证据：[connectToServer Promise.race(invoke, timeoutPromise)](../../src/stores/serverStore.ts#L159-L207)，超时仅前端 reject，[setTimeout 未 clear](../../src/stores/serverStore.ts#L161-L166)，Rust 端 `SshSession::connect` 仍在跑。
- 影响：超时后可能残留半开会话/悬挂 timer；若稍后 Rust 连接成功，session 存在于后端 map 但前端已判失败 → 泄漏会话。
- 优先级：P2。

### F-4 🟡 StrictMode 下 PTY 初始化双跑风险
- 证据：[main.tsx 包裹 React.StrictMode](../../src/main.tsx#L6-L9)；[TerminalView init 有 `if (termRef.current) return` 守卫](../../src/components/TerminalView.tsx#L169-L207)。
- 影响：🟡 开发模式下 effect 双执行，守卫可挡重复 init，但 cleanup→re-init 时序需实测确认不会重复 `ssh_start_pty`。列为待验证。

### F-5 🟢 Tab/Pane 结构持久化与重启恢复
- 证据：[persistTabs / loadConfig 恢复 tab 结构并自动重连](../../src/stores/serverStore.ts#L265-L309)、[save_tabs 后端](../../src-tauri/src/config.rs#L398-L410)。
- 结论：结构恢复能力已具备（sessionId/state 不持久化，合理）。受 F-1 影响，分屏恢复不完整。

- 证据：[CommandPalette](../../src/components/CommandPalette.tsx)、[快捷键系统](../../src/App.tsx#L92-L254)、[ImportModal 多格式导入](../../src/components/ImportModal.tsx)、[ServerList 分组/拖拽](../../src/components/ServerList.tsx)。

## 2.0 产品定位与对标基线

- 真实形态：**远程 SSH/SFTP 终端管理器**（对标 Xshell / Tabby / Termius），非本地 shell 终端（见 [01 A-2](./01_现状审计与问题清单.md#a-2--不存在本地-pty--本地-shell与任务书假设不符需澄清)）。
- 对标理念（仅借鉴交互范式，不复制商业代码、不编造竞品实时事实）：
  - **iTerm2**：分屏、Profile、即时回放、触发器、密码管理器。
  - **Warp**：AI 命令建议、块（block）级输出、命令面板。
  - **Windows Terminal**：标签/分屏、主题、settings.json 化配置。
- 本产品差异化机会：**「多主机批量运维 + AI 辅助 + 强安全边界」三位一体**。当前批量与 SSH 底座扎实，AI 与安全边界是短板。

## 2.1 多会话 / 标签管理

### 现状（已存在能力 🟢）
- Tab 与 serverId 解耦，支持同一服务器多开、分屏：[TerminalTab.panes](../../src/types/index.ts#L50-L66)。
- Tab 结构持久化与重启恢复：[persistTabs/loadConfig](../../src/stores/serverStore.ts#L265-L309)。

### 缺口与优先级
| 缺口 | 证据 | 优先级 |
|------|------|--------|
| 分屏断线重连只恢复 pane[0]，其余 pane 永久「连接中」假死 | [reconnectTab](../../src/stores/serverStore.ts#L830-L849) | P1（违反 P-3） |
| 一个长命令冻结所有标签输入（全局单 Mutex） | [01 C-1](./01_现状审计与问题清单.md#c-1--全局-sessions-单-mutex-跨-await-持锁队头阻塞) | P0 |
| 无「一键断开全部/重连全部」与连接状态总览 | 未见对应命令 | P2 |
| Tab 无未读输出/活动指示（后台标签有新输出无提示） | 未见 bell/活动标记 | P2 |

### 建议
- 引入 per-session 锁与「会话健康总览」面板；重连逻辑改为遍历全部 pane（详见 [03](./03_技术架构与性能优化.md)）。
- 后台标签输出到达时显示活动点/响铃标记（xterm `bellStyle` + 自定义事件），提升多会话可用性。

## 2.2 PTY 渲染与滚动

### 现状
- xterm.js 渲染，`convertEol:true`，逐事件 `term.write`：[TerminalView 初始化](../../src/components/TerminalView.tsx#L180-L196)、[ptyOutputHandler](../../src/components/TerminalView.tsx#L210-L255)。
- 仅默认 DOM renderer，无 WebGL/Canvas addon：[package.json 依赖](../../package.json#L20-L21)。

### 缺口与优先级
| 缺口 | 影响 | 优先级 |
|------|------|--------|
| 高频输出无批处理（每块一次 write） | `cat bigfile`/`yes` 抖动、CPU 高 | P1 |
| 无 WebGL 渲染加速 | 大回看+高频输出卡顿（🟡 待实测） | P2 |
| `convertEol` 与远程 PTY `\r\n` 可能重复处理 | 特定程序输出错位（🟡 待验证） | P2 |
| scrollback 上限/搜索/回放未配置 | 长日志无法回看检索 | P2 |

### 建议
- 输出按 16ms 合并窗口批量 `write`，配合 xterm `write(data, callback)` 做背压（详见 [03](./03_技术架构与性能优化.md)）。
- 评估启用 `@xterm/addon-webgl`（规划新增依赖），失败回退 canvas/DOM。
- 明确 scrollback（如 10000 行）+ 接入 `@xterm/addon-search` 支持终端内检索。
- 复核 `convertEol` 必要性：远程 PTY 一般已处理换行，建议实测后决定是否关闭。

## 2.3 复制 / 粘贴

### 现状
- xterm 默认选区复制；未见「粘贴前确认」「多行粘贴保护」「括号粘贴模式(bracketed paste)」处理。

### 缺口与优先级
| 缺口 | 影响 | 优先级 |
|------|------|--------|
| 粘贴含危险命令/多行脚本无确认 | 误粘贴即执行，违反 P-2 | P1 |
| 无 bracketed paste 处理 | 多行粘贴被逐行立即执行（远端 shell 行为） | P2 |
| 选区/剪贴板与系统集成的跨平台差异未显式处理 | macOS/Windows 复制快捷键差异 | P2 |

### 建议
- 粘贴入口统一过危险命令检查（P-2），多行/含换行的粘贴弹确认「将粘贴 N 行，是否继续」。
- 评估启用 bracketed paste，避免多行脚本被逐行触发。

## 2.4 主题 / 字体 / 外观

### 现状（已存在能力 🟢）
- 响应式更新终端选项（光标样式等），设置变更即时生效：[useEffect opts](../../src/components/TerminalView.tsx#L293-L299)。
- 支持自定义 CSS 注入与背景图：[custom_css](../../src/components/TerminalView.tsx#L352-L368)、[背景图 file://](../../src/components/TerminalView.tsx#L336-L349)。

### 缺口与优先级
| 缺口 | 影响 | 优先级 |
|------|------|--------|
| custom_css 无 CSP 约束下任意注入 | 安全面扩大（见 [01 B-5](./01_现状审计与问题清单.md#b-5--csp-关闭--宽泛-capabilities--自定义-css-注入)） | P1 |

| 无主题预设（solarized/dracula 等）与字体连字(ligature)开关 | 个性化不足 | P2 |

### 建议
- 主题/字体收敛到 settings token；custom_css 与背景图路径纳入白名单与 CSP（详见 [04](./04_数据安全与可靠性.md)）。
- 提供内置主题预设，减少用户手写 CSS 需求。

## 2.5 命令历史 / Snippet / 命令面板

### 现状（已存在能力 🟢）
- Snippet 快捷命令、命令面板、快捷键系统真实存在：[CommandPalette](../../src/components/CommandPalette.tsx)、[快捷键](../../src/App.tsx#L92-L254)、[executeSnippet](../../src/stores/serverStore.ts#L646-L656)。

### 缺口与优先级
| 缺口 | 影响 | 优先级 |
|------|------|--------|
| Snippet/批量执行直写 PTY，无危险命令确认 | 违反 P-2，不可逆破坏 | P0 |
| 无跨会话命令历史检索（本地记录） | 复用效率低 | P2 |
| Snippet 无变量/占位符模板 | 批量场景需手改 | P2 |

### 建议
- 所有「命令落地 PTY」的入口（手输回车、Snippet、批量、AI）统一经过危险命令网关（P-2，详见 [04](./04_数据安全与可靠性.md)）。
- 增加本地命令历史（脱敏后存储，遵守 P-4）与 Snippet 模板变量。

## 2.6 Profile / 环境管理

### 现状

### 缺口与优先级
| 缺口 | 影响 | 优先级 |
|------|------|--------|

## 2.8 SSH 连接体验

### 现状（已存在能力 🟢）
- 密码/公钥认证、跳板机 ProxyJump、SFTP、三种端口转发、密钥生成、诊断（ping/port/traceroute）均真实实现（见 [01 A-1](./01_现状审计与问题清单.md#a-1--真实-ssh-全栈后端russh)）。

### 缺口与优先级
| 缺口 | 影响 | 优先级 |
|------|------|--------|
| 主机公钥恒接受，无 known_hosts 确认 UI | MITM（见 [01 B-1](./01_现状审计与问题清单.md#b-1--ssh-主机公钥恒自动接受无-known_hosts-校验mitm)） | P0 |
| 诊断命令 host 未转义 → 命令注入 | 见 [01 B-2](./01_现状审计与问题清单.md#b-2--诊断命令字符串拼接未转义--远程命令注入) | P0 |
| 连接超时不取消底层 Rust 连接 | 半开会话泄漏（见 [01 F-3](./01_现状审计与问题清单.md#f-3--连接超时用-promiserace未取消底层-rust-连接)） | P2 |
| 重连固定 3s 无退避 | 服务器不可达时反复冲击 | P1 |
| 无 known_hosts / 指纹管理界面 | 用户无法审阅信任的主机 | P1 |

### 建议
- 首次连接弹「主机指纹确认」对话框（展示 fingerprint），用户确认后写入 known_hosts；变更时强警告（详见 [04](./04_数据安全与可靠性.md)）。
- 诊断命令统一走转义/参数化（复用已有 [shell_escape](../../src-tauri/src/ssh.rs#L920-L923)）。

### 建议（产品层）
1. **能补齐的补齐**（基于已存在的 [aiClient 抽象层 🟢](../../src/services/aiClient.ts#L6-L241)，非另起炉灶）：
   - 命令解释/错误分析：从终端选区/最近输出取词，真正传入组件；解决 Ctrl+Shift+E 与 SFTP 的快捷键冲突（重新分配或加修饰键）。

2. **不能补齐的下线或标注**：Cloud Agent 改为「本地预览，未接云」或移除；`src/agent/` 死代码删除。

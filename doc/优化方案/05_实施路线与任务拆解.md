## 5.7 兼容与回滚总原则

1. 每任务独立提交，可单独 `git revert`（本方案不执行任何 commit）。
2. 行为变更（host key 严格化、CSP、危险命令网关）一律加**配置开关**，默认安全、可回退。
3. 数据格式变更（凭证加密、ExecResult 扩展）保留**向后兼容读取**至少一个版本 + 迁移脚本。
4. 新增依赖（WebGL/钥匙串/Markdown 库）须评审体积与平台兼容性，失败有回退路径。
5. 任何阶段若验收不通过，**不进入下一阶段**（尤其阶段一 P0）。

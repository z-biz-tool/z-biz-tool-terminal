## 功能总览

### 🔌 SSH 连接

| 功能 | 说明 |
|------|------|
| PTY 实时终端 | 基于 russh 的真 PTY 模式，xterm-256color，双向流式交互 |
| 密码认证 | 支持密码登录 |
| 密钥认证 | 支持 PEM 格式私钥登录 |
| 跳板机 (ProxyJump) | 通过中间主机级联连接目标服务器 |
| 自动重连 | 会话意外断开时自动尝试重新连接，并把「第几次在连 / 还剩几秒重试 / 为什么停了」显示在面板与顶部状态条上 |
| Keep-Alive 保活 | 可配置 SSH keepalive 间隔，防止连接超时断开 |
| 连接超时控制 | 可设置连接超时时间（5-300 秒） |
| SSH Agent 转发 | 可选开启 Agent Forwarding |
| Quick Connect Bar | 快速输入 host/user 连接，无需添加服务器配置 (Cmd/Ctrl+L) |
| 连接历史 | 记录最近 20 条连接，一键重连 |

### 📁 SFTP 文件管理

| 功能 | 说明 |
|------|------|
| SFTP 浏览 | 真实 SFTP 协议浏览远程文件系统，兼容 ls 回退；面板按标签页认会话，列表与它属于哪个会话成对记录，切标签页只列自己那台、各自记住浏览到哪一级 |
| 上传/下载 | 传输按真实字节数显示进度：后端 32 KB 分块、250 ms 节流上报，总大小取不到时只标「大小未知」而不画猜出来的百分比；成败以 `ExecResult.success` 为准。右侧同时给出**用时 / 均速 / 约剩**（由字节数与注入时钟算出的平均速度推出，卡住时用时每秒自走、剩余随之恶化；大小未知时不给剩余，算不出速度时只说「尚无数据」） |
| 落盘白名单 | 任何写本地的 SFTP 操作都先过 `paths::prepare_write`：只认临时目录与家目录、拒绝 `..`，缺失父目录按 0700 递归补出；被拒时回 `success:false` + 原因，不抛异常 |
| 批量传输 | 一批 N 个文件有独立一行的**整批进度**（`下载 3 个文件 · 第 1/3 · a.txt · 已结束 0/3`）、整批字节 `整批 15.0 MB / 30.0 MB · 50% · 约剩 19.0s`（任何一条大小未知就宁可不给百分比与约剩）与「取消剩余 N 个」按钮 —— 取消只挡还没开始的，正在传的那条会传完；上传同样先去重再落名，两个同名本地文件不再互相覆盖 |
| 批量下载 | 多选只弹**一次**目录选择器；落点文件名净化 + 批内去重，改过名会在汇总里点名；本地已存在的文件一律不覆盖（`overwrite:false` → 后端 `prepare_write_new` 拒写），整批结束只出一条「已下载 N / 跳过 M / 失败 K」汇总 |
| 拖拽上传 | 拖拽本地文件到 SFTP 面板直接上传 |
| 拖拽下载 | 拖拽远程文件到下载区域触发下载 |
| 多选操作 | Shift/Ctrl 多选，Ctrl+A 全选 |
| 批量下载 | 多选文件批量下载 |
| 批量删除 | 多选文件批量删除（含确认） |
| 新建文件夹 | 远程创建目录 |
| 重命名 | 远程文件/目录重命名 |
| 右键菜单 | 完整的右键上下文菜单 |
| 面包屑导航 | 路径面包屑快速跳转 |
| 路径输入 | 手动输入路径直接跳转 |
| 列排序 | 按名称/大小/权限/修改时间排序 |
| 键盘导航 | 方向键/Enter/Delete/Backspace 键盘操作 |
| 远程文件编辑 | 双击文件下载到临时目录 → 系统编辑器打开 → 自动检测修改 → 上传回服务器。副本落点由「会话 id + 远端路径哈希」定名，远端文件名不参与目录结构，同名不同路径各持一份、互不顶掉；回传锁定**开编辑时那份**会话（切走标签页也不会把 A 的内容推给 B），一次本地保存只回传一次，会话断开则停止监听并说明改动不会自动回传 |
| ZMODEM 传输 | 检测 rz/sz 握手，支持终端内文件传输 |

### ⚡ 效率工具

| 功能 | 说明 |
|------|------|
| 命令面板 | Cmd/Ctrl+K 或 Cmd/Ctrl+Shift+P，模糊搜索服务器/命令/操作；已打开的会话单列一组（「已打开会话」，不说"已连接"），**只有 store 里那条活跃标签才带「当前」**，连接中/连接失败/已断开按状态各标各的（认不出的状态原样露出、不猜颜色），说明句与徽标同进同退；**组序按命中项首次出现排，↑/↓ 走的、鼠标点的、屏幕上看到的是同一条序列**，高亮行自动滚进视野 |

| 快捷命令 (Snippets) | 代码片段管理，分组、搜索；点击即发送到**当前标签的当前面板**（危险命令同样先过二次确认，未发出时会如实提示"命令未发送"） |
| 批量命令执行 | 多台服务器同时执行同一命令，实时输出对比 (Xshell 级功能) |
| 快捷键系统 | 完整的键盘快捷键支持，可查看快捷键列表 (Cmd+/) |

### 📝 日志与审计

| 功能 | 说明 |
|------|------|
| 会话日志 | 自动记录 SSH 会话输出到 ~/.z-terminal/logs/，带时间戳；文件与目录权限 0600/0700 |
| 日志脱敏 | 口令、私钥、API Key 等在落盘前替换（跨数据块的行缓冲 + ANSI 剥离 + PEM 状态机） |
| 日志浏览 | 查看历史会话日志 |
| 日志删除 | 删除指定日志文件 |
| 自定义日志目录 | 可配置日志存储路径 |
| 安全审计轨迹 | `~/.z-terminal/audit.log`（JSONL 追加，0600，超 2 MB 滚动一代）：连接/断开、主机密钥每一条判定、命令执行、配置导出与密钥保存、危险命令的**放行与拒绝**、AI 建议填入、网关被关小的旁路 |
| 审计查看与导出 | 设置 → 审计日志：最近 100 条（动作/主机/命令/结论），可导出 CSV（带 BOM、防公式注入）或 JSON；导出路径受白名单约束（家目录与临时目录） |
| 主机信任管理 | 设置 → 主机信任：按主机聚合列出 known_hosts 的算法与 SHA-256 指纹（与连接弹窗同一口径，可一键复制比对），支持主机/端口/算法/指纹搜索、`ssh-rsa`/`ssh-dss` 弱算法提示、命中服务器时标注名称；撤销需确认并如实列出会一并删除的算法条数，动作写入审计 |
| 命令历史脱敏 | 命令写进本地历史前先替换口令类参数（`KEY=VALUE`、`--password xxx`、mysql 式 `-pXXX`、URL 内嵌 `user:pass@`、整段 PEM）为 `****`，这一层不可关闭；纯数字端口 (`-p443`) 与 URL 型 token 值不会被误伤 |
| 环境标记 | 服务器可标 `生产/预发/开发`（自由文本亦按别名归一化，认不出即按未标注处理、不猜）：侧栏三色徽标、仅生产环境进标签页并带红色顶边；危险命令确认框逐条显示主机所属环境并汇总"清单中有 N 台生产环境主机"，该前缀同时写进审计的受影响主机清单，事后能复原生产机是否在爆炸半径内 |

审计写入是尽力而为：磁盘满、权限异常只会 `eprintln!`，绝不会让用户的连接或命令因此失败。审计永不记录密码与私钥内容。

## 🔐 前端能力与本地文件边界

- WebView 侧只保留三类能力：原生对话框（open/save/message）、剪贴板写入、Tauri 核心事件/路径。`fs:*` 与 `shell:*` 已从 `src-tauri/capabilities/default.json` 摘除，前端不再直接读写磁盘或调用外部 open。
- 所有本地文件读写都经 Rust 命令，并受白名单约束（`src-tauri/src/paths.rs`）：只允许**家目录**与**系统临时目录**内的真实路径（canonicalize 后判定，拒绝 `..` 与指向范围外的符号链接）。生成的私钥固定 0600，代为创建的 `~/.ssh` 为 0700。
- 因此从 U 盘/挂载卷（如 macOS `/Volumes/...`）直接上传需要先把文件复制到用户目录；放宽只需在 `allowed_roots()` 增加一项。
- 已启用 CSP（`src-tauri/tauri.conf.json`）：脚本/样式/连接按指令白名单，`object-src`、`frame-src` 为 `none`。`connect-src` 覆盖 https 与 `localhost`（Ollama、dev HMR）；自建网关若走局域网明文 http，需在该处补来源。

- **antd v6 的废弃属性已清零（§7.33）**：`destroyOnClose`→`destroyOnHidden`（7 处）、`maskClosable={false}`→`mask={{ closable: false }}`（3 处）、`Space direction`→`orientation`（4 处）、`Spin tip`→`description`、`Alert message`→`title`（9 处）。挂整棵 `App` + 打开 SFTP 面板时控制台的 deprecation 警告实测从 **3 条 → 0 条**；点危险命令确认框的遮罩仍然既不批准也不撤销（`pendingConfirmCount()` 仍为 1、promise 未 resolve）。**`List` 这笔债已在 §7.38 偿清**：三处（命令面板 / 云代理 / 最近连接）换成 `_shared/ItemRows` 的 `ItemList`/`ItemRow`（`<ul role=listbox aria-label>` + `<li role=option aria-selected>`），守卫从"名单不许扩大"收紧成"一个都不许再用 `List`"，包体顺带小约 9 kB；命令面板的 ↑↓ 走位仍与 `aria-selected` 行号逐条一致（实测 0→3→10、再 9 次 ↑ 回 0）。
- **SFTP 面板的会话身份逐个入口都在浏览器里量过**：修前工具栏与 ⌘⇧E 打开面板时 `sftp_list` **一次都没发**（`sftpVisible:true` + 空面板 + 零提示，因为调用方 `.catch(() => {})` 吞掉了报错），双击进目录只得到「会话未连接」—— 整个面板在已连接的会话上做不了任何事。修后每个入口恰好 1 次且 `sessionId` 等于该标签页自己的会话；切标签页只列新一台（旧会话的行不露出）、每会话记住自己浏览的层级；拿 tab id 去列目录会如实抛「会话不存在: tab-a」且不污染当前列表；无会话与列目录失败各有诚实空态（「会话未连接」/「无法读取目录 /：Permission denied (os error 13)」）而不是「目录为空」。同一轮顺带挖出「一次本地保存引发无限重复回传」：实测 13 s 内 8 次 `sftp_upload` + 8 条成功提示，修后 1 次，且切走标签页后回传仍用开编辑时那份会话。
- **「编辑远端文件」的落点已在同一通道里按真 IPC 报文量过**：目录列表（由远端服务器给，是最不可信的输入）里塞一条 `../../../../etc/passwd`，双击后 `sftp_download` / `get_file_modified_time` / `open_file_with_default_app` 三个口拿到的路径**逐字相同**且为 `临时目录/z-terminal-edit/<会话-哈希>/passwd`（不含 `..`、不含 `//`）；`/opt/app/nginx.conf` 与 `/etc/nginx.conf` 得到两份不同副本，两个监听器的回传各带自己的远端路径与自己的本地副本（3 条下载 → 去重 3 个落点）；重复双击同一条 = 额外下载 0 次；拉取失败时后两个口一次都没调（不会打开一份不存在或上次残留的副本）。把旧写法塞回去的变异臂在同一探针下实测产出 `/var/folders/…/T//z-terminal-edit/../../../../etc/passwd` 且同名两条共用一个落点（去重 2 个），并把守卫红 4 例 —— 测完 `cmp` 逐字节还原、`grep MUTATION-CONTROL` 0 残留。Rust 侧另有三臂变异对照：摘掉 `.recursive(true)` ⇒ 干净安装现场原文复现（`创建目录失败 …/sess-1: No such file or directory`），保留校验但仍写 `local_path` ⇒ 红 1 例，整道闸删掉 ⇒ 红 4 例。
- **其余 GUI 运行时未验证**：主机密钥确认弹窗、审计日志 tab、WebGL 渲染器能否在 WKWebView 里建起上下文，目前都只有单元与静态层面证据，`npm run tauri dev` 未在本机跑起来（需要真机 WebView 与真 SSH 服务端）。SFTP 的传输反馈形态、编辑副本落点与面板会话身份（§7.27–7.29）已在浏览器里量过（上三条），但**传输/删除/改权限的端到端行为仍未对过真账号**，PTY 端到端同样没有覆盖；**新增的落盘白名单尤其需要一个真机确认**：保存对话框选到家目录外的挂载点（`/Volumes/...`）时后端会拒，这条拒绝文案在真实传输条上的呈现未取过样。WebGL 的不确定风险已被回退路径兜住：建不起来或上下文丢失即退回 DOM 渲染，最坏情况等同改动前。
- 安全网关是"防误操作"级别的前端防线：远端主机的真实权限边界仍在服务端，关掉开关即完全旁路（审计轨迹会记下 `command_gate_bypassed`）。
